# Custom React Hooks

A lightweight collection of reusable React hooks to simplify common patterns and enhance your components.

## Included Hooks

### [useCounter](./src/useCounter)
A simple hook for managing counter state with increment and decrement operations.

### [useFetch](./src/useFetch)
A data-fetching hook for loading remote data with built-in loading and error states.

### [useForm](./src/useForm)
A form state management hook to handle form inputs, validation, and submission.

## Quick Start

### Install Dependencies
```bash
bun install
```

### Development
```bash
bun dev
```

### Production Build
```bash
bun start
```

## About

This project uses [Bun](https://bun.sh), a fast all-in-one JavaScript runtime, for optimal performance and developer experience.
